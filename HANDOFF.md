## Запуск и проверки

Фактическая среда этой сверки: Python 3.14.6, зависимости локально в игнорируемом `dist/runtime-pkgs` через `PYTHONPATH`. README для новой копии создаёт собственную `.venv`; Python 3.11 ещё не проверен. Ключи хранятся только в локальном `.env`/переменных процесса; значения не отправлять в чат или Git.

Из корня репозитория:

```powershell
$env:PYTHONPATH='dist\runtime-pkgs'
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
python -m mechanic.evaluate
python -m pytest tests neurodvs_hackathon_mock_2026-11-16/tests -q -p no:cacheprovider
node --test tests/frontend.test.cjs
& 'dist\openspec-cli\node_modules\.bin\openspec.cmd' validate hackathon-mvp --strict
```

Первая команда использует сохранённые verified_ocr без Tesseract. Для нового OCR использовать scripts/ocr_windows.ps1 и порядок сверки/импорта из README. Все результаты распознавания должны оставаться внутри corpus/.

ML на 8001 и ТОиР на 8002 управляются оператором: если они уже работают, не запускать второй экземпляр и не останавливать существующие процессы. В этой сверке попытка локального запуска не привела к прослушиванию портов, созданные процессы остановлены без заявок. Проверка работающих сервисов через приложение включается явно `MECHANIC_LIVE_CHECKS=1`. В прежнем блоке 8 так пройдены все 195 пар без POST /tickets.

Приложение запускается отдельно:

```powershell
& 'E:\хакатон\.venv\Scripts\python.exe' -m uvicorn mechanic.app:app --host 127.0.0.1 --port 8000
```

Адрес http://127.0.0.1:8000. Если порт занят, проверить владельца; не завершать все процессы Python. Актуальность кода ранее запущенного приложения не подтверждена. После обновления нужен перезапуск только собственного процесса приложения.

По указанию пользователя единственный порт приложения — **8000**, адрес http://127.0.0.1:8000. Дополнительный экземпляр на 8010 не запускать; упоминания этого порта и прежних PID в отчётах относятся к историческим проверкам. При смене настроек перезапускать только экземпляр приложения на 8000. Порты 8001/8002 принадлежат сервисам организатора и управляются оператором.
