# Сторонние компоненты

Зависимости приложения закреплены в requirements.txt. Python и SQLite используются как среда выполнения и локальная база данных. В продукт входят FastAPI (MIT), Starlette (BSD-3-Clause), Pydantic (MIT), Uvicorn (BSD-3-Clause), HTTPX (BSD-3-Clause), Jinja2 и MarkupSafe (BSD-3-Clause), SnowballStemmer (BSD-3-Clause), PyMuPDF/MuPDF (AGPL либо коммерческая лицензия). Pytest (MIT) — инструмент проверки. Полные уведомления и лицензии зависимостей сохраняются в установленных пакетах; транзитивные зависимости учитываются при упаковке.

PyMuPDF используется только для локальной подготовки PDF, OCR при наличии Tesseract и визуальной проверки. Его [официальные условия](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright) предусматривают AGPL или коммерческую лицензию. Лицензия всего проекта пока не объявлена; перед публичным распространением приложения необходимо определить совместимый режим лицензирования. Наличие открытого репозитория само по себе не заменяет выполнения условий лицензии.

Опциональный Tesseract OCR (Apache-2.0) и языковые данные устанавливаются отдельно. OCR не считается проверкой корректности технических чисел.

Источники языковых данных Tesseract: [официальный tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast), файлы eng.traineddata и rus.traineddata. Эти файлы в рабочей среде недоступны. Для задачи 3.2 успешно использован установленный Windows.Media.Ocr с русским языком: семь страниц распознаны локально и визуально сверены. Windows OCR является компонентом ОС, не включается в архив приложения и не требует внешнего OCR API. В поставку входит только собственный вспомогательный scripts/ocr_windows.ps1; тексты распознавания и изображения остаются локальными.

Выданный архив neurodvs_hackathon_mock_2026-11-16 сохранён без изменений; это внешние синтетические сервисы и данные организатора. Их тесты не являются тестами приложения. Три DOCX и исходные Markdown — материалы задания. Возможность публикации архива/материалов задания проверяется по условиям организатора.

PDF заводских руководств и текстосодержащие RAG-индексы, OCR-выгрузки и дампы не входят в публичную поставку. Они не являются собственными материалами команды. Перечень руководств, редакций и страниц приведён в mechanic/manuals.py и design.md.

Внешние генеративные API: OpenAI API и Yandex AI Studio. Фрагменты документации передаются только выбранному оператором провайдеру. Автоматической смены провайдера нет. Сейчас настроена OpenAI `gpt-6-luna`: короткий запрос вернул валидный JSON, но полный прогон с руководствами остановлен автоматической проверкой безопасности до отправки данных. Фактическую модель принятого демо и использование API нужно указать в описании сдаваемого продукта после полной приёмки.

Контракты адаптеров сверены с официальными справочниками [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat) и [Yandex TextGeneration.Completion](https://aistudio.yandex.ru/ru/docs/ai-studio/text-generation/api-ref/TextGeneration/completion). Для Yandex используется актуальный ai.api.cloud.yandex.net, JSON-решение агента не зависит от наличия native tool calling.
