Готовый файл полностью декодируется, имеет аудио и сохраняет видеопоток исходного MP4. Кадры с рекомендацией и источниками просмотрены. Человеческое прослушивание остаётся отдельной проверкой. Сценарий M333YK47 / S-0005 показал отклонение по топливоподаче, сверку меток и процедурный источник 236 РК, физическая страница 257. Ключевые кадры результата, предпросмотра, номера заявки, ответа с источником и сбоя просмотрены. Громкость голоса нормализована в два прохода к −16 LUFS, целевой true peak −1,5 dBTP. Реплики размещены по времени событий. Максимальное ускорение полной версии около 4,4%, короткой — 11,9%.

Исходник, журнал событий, субтитры SRT, планы речи и машинный отчёт находятся в игнорируемом dist/video-demo/. До успешного дубля два прогона M739BA198/S-0103 завершились отказом верификатора.
