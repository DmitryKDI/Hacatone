# Проверка доступа к LLM после настройки ключа

26 ноября 2026 года. Продолжение задач 1.4, 5.7 и 8.1 после сообщения оператора о настройке API.

## Результат

- Settings.load() читает заполненные ключ и модель OpenAI; llm_problem() возвращает null. Настроенная модель — gpt-6-luna. Её существование и доступность для этого аккаунта ещё не подтверждены ответом API.
- Наш процесс приложения на 8010 перезапущен после изменения .env; /api/session возвращает provider=openai и llm_problem=null. Текущий PID — 14572. Отсутствие предупреждения означает наличие настроек, а не успешную проверку доступа.
- Один вызов штатного Provider.json с коротким запросом JSON без руководств завершился сетевой ошибкой до HTTP-ответа. DNS api.openai.com разрешается. Проверка TCP-соединения с портом 443 выявила PermissionError, errno=13, WinError=10013: доступ к сокету запрещён правами. Это подтверждает отказ исходящего соединения в текущей среде, но не определяет конкретное правило Windows/защитного ПО.
- HTTP-ответ API не получен: действительность ключа, допустимость региона, биллинг/квоты и модель не проверены. Затраты и задержки успешного обращения не измерены. Подмена модели, смена провайдера, отключение защиты или обход запрета не выполнялись.
- Yandex не настроен: полный набор ключа, folder_id и модели отсутствует. Проверка его DNS не подтверждает доступ к аккаунту/API.

## Выполненная независимая проверка

ML на 8001, ТОиР на 8002 и наше приложение на 8010 отвечают HTTP 200 на /openapi.json. Сервисы организатора не запускались и не перезапускались.

Повторно выполнен существующий opt-in тест:

```powershell
$env:MECHANIC_LIVE_CHECKS='1'
& 'E:\хакатон\.venv\Scripts\python.exe' -m pytest tests/test_live_services.py -q -p no:cacheprovider
Remove-Item Env:MECHANIC_LIVE_CHECKS
```

Один тест прошёл: 195 настоящих запросов /diagnose через приложение, пять моделей двигателей, 111 normal / 69 anomaly / 15 check_failed. Преднамеренно отключённая в этом тесте генерация проверяет сохранение ML-результата и предупреждений при недоступности LLM. Попытки отправки без предпросмотра заблокированы до ТОиР, исходящих запросов ТОиР — ноль. Локальный подробный результат: corpus/stage-8-live.json. Это не проверка реальной генерации.
