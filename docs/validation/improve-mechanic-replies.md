# Готовность «Цифрового механика» к записи

27–28 ноября 2026 года, МСК. **Проверенный сценарий F7 готов к записи на настроенном локальном стенде.** Сквозной прогон использовал `gpt-6-luna`, локальные PDF и исходные приложения ML и ТОиР организатора в изолированном стенде. ТОиР вернула тестовую заявку `TKT-0001`. На стенде для записи номер заявки нужно получить заново.

## Проверенный сценарий

1. Выбрать `M333YK47 / S-0005` и показать отклонение по топливоподаче. Сверка меток нужна для уточнения причины.
2. Спросить «Нужно ли вводить измеренный угол?». Показать прямой ответ и ссылку на физическую страницу 257 РК.
3. Отметить «метки не совпадают». Открыть предпросмотр, показать работу и источник. Сменить приоритет и подтвердить обновлённую заявку. До подтверждения запросов в ТОиР нет. Повтор команды отправки и старое подтверждение получили HTTP 409.
4. На той же машине спросить «Какое давление масла допустимо на прогретом двигателе при номинальной частоте и на холостом ходу?». В контрольном прогоне Luna сослалась на физическую страницу 19 РЭ.
5. Выбрать `P456AT178 / S-0003`. Карточка требует повторной записи. Отправка снова получила HTTP 409, в ТОиР осталась одна заявка.

Дополнительные проверки прошли. При совпадении меток результат сохранился, а заявка на регулировку не готовится. Для спорного условия проверки зазоров ЯМЗ‑236 показаны физические страницы 31 РЭ и 276 РК. Страница 269 РК относится к проверке перед началом и после обкатки. Условие демонстрации выделено отдельно, зависимая заявка заблокирована.

В браузере при ширине 1280 и 320 CSS-пикселей действие видно до раскрытия подробностей. Диагностика и источники доступны с клавиатуры. Чтение карточки человеком за десять секунд, физический смартфон и полная длительность видеозаписи ещё не измерены. ## Инструкции и проверка Luna

Для поиска используется короткая отдельная инструкция. Генератор выбирает идентификатор выдержки, а приложение восстанавливает буквальный текст и его страницу из локального каталога. Отдельный запрос к Luna проверяет применимость, смысл и противоречия. Сервер сверяет числа, единицы и условия и блокирует непроверенную рекомендацию. Для заявки обязательны проверенные работы и отдельное подтверждение механика.

При исправлении ответа по руководству приложение сохраняет уже подтверждённые утверждения. Они снова проходят проверку достаточности и конфликтов вместе с исправлениями. Предыдущий вопрос механика передаётся верификатору для определения этапа работы. Неподтверждённая работа блокирует заявку целиком.

OpenAI указывает, что `gpt-6-luna` не поддерживает fine-tuning. В проекте используются инструкции, локальный поиск и проверка ответа. [Карточка модели](https://developers.openai.com/api/docs/models/gpt-6-luna) · [Рекомендации по инструкциям](https://developers.openai.com/api/docs/guides/reasoning-best-practices).

## Регрессия

Полный прогон с Luna дал 15 ответов с ожидаемыми страницами из 16 положительных вопросов. По ремню водяного насоса ЯМЗ‑236 показаны обе версии, физические страницы 28 и 138 РЭ. Чтобы выбрать процедуру, нужно установить комплектацию насоса. Все восемь отрицательных вопросов заблокированы до обращения к модели. Восемь проверок верификатора прошли, включая четыре неверные привязки. Автоматическая сверка нашла все 35 показанных выдержек на указанных физических PDF-страницах.

Проверка ответов выявила неполную процедуру по клапанам ЗМЗ‑5234 и перенос части инструкции через границу двух страниц. В повторе итоговый ответ сослался на страницы 20–21, сохранил положение первого цилиндра на такте сжатия, способ измерения и последовательность для остальных цилиндров. В подробностях часть действий повторилась. По ЯМЗ‑536 повторный ответ сохранил максимальную длительность превышения температуры, которая теперь проверяется сервером отдельно.

Для сравнения, до оптимизации были 12 ответов с ожидаемым источником, 544 233 токена и медиана 9,96 с по положительным вопросам. В новом полном прогоне — 440 209 токенов и медиана 7,88 с, примерно на 19% меньше токенов. Это результаты отдельных прогонов.

Локально прошли 178 Python-тестов и 12 JS-тестов. Один Python-тест живых служб пропускается в стандартном наборе. Живой прогон использует их приложения в изолированном режиме. OpenSpec 2.2.0 принял пакет в строгом режиме.

Детальные логи и тексты выдержек хранятся локально в `dist/replies-luna-final/`.

## Повтор через внешний API 28 ноября

В журнале запроса записаны HTTP-статус, этап обработки, поля контекста, номера страниц и количество выдержек. Поисковый вызов получает вопрос и модель двигателя. Генератор получает отобранные фрагменты и идентификаторы выдержек. Верификатор получает утверждения с привязанными источниками и историю, нужную для понимания этапа работы. На проводе используется строгая JSON-схема. Секреты и тексты запросов в журнале формы входа отсутствуют. Для F7 верификатор получает синтетический результат диагностики без идентификаторов машины и сессии.

До правок все 67 обращений в API получили HTTP 200. После правок все 62 получили HTTP 200, все 46 показанных выдержек найдены на заявленных физических страницах, а восьмичастная проверка верификатора прошла. В обоих прогонах F7 создал ровно одну заявку в изолированной ТОиР.

В вопросе об обкатке ЯМЗ‑236 повторные формулировки из той же выдержки больше не вытесняют подтверждённые утверждения. После правки модель дала ответ со страницы 267. Для сцепления ЗМЗ‑409 обе сверенные выдержки со страницы 196 теперь доходят до модели. Полный повтор показал разночтение между разрешением правки в таблице неисправностей на странице 194 и правилом замены непригодных дисков на странице 195. Заявка по этому разночтению заблокирована.

Для вопроса о снятии ремня ЯМЗ‑536 в инструкции отделены ремонтные действия от проверок. Сервер проверяет наличие самого шага снятия, а подтверждённый фрагмент со страницы 27 добавляется после подготовки, если модель его опустила. Целевой запрос вернул подготовку натяжника, снятие ремня и завершение операции. У проверки Luna предусмотрен один повтор при обрыве JSON на лимите выходных токенов. В локальной регрессии прошли 183 Python-теста и 12 JS-тестов.

В заключительном целевом прогоне ответы об обкатке ЯМЗ‑236, снятии ремня ЯМЗ‑536 и клапанных зазорах ЗМЗ‑5234 получили ожидаемые страницы, а 11 показанных выдержек найдены в PDF. Повтор вопроса о сцеплении ЗМЗ‑409 после уточнения достаточности ответа снова выявил разночтение на страницах 194–195 РК. Luna получила обе сверенные выдержки со страницы 196. При подтверждённом разночтении сервер показывает источники и блокирует зависимую заявку.
