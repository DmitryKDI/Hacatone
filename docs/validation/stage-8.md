Это не браузерный тест и не доказательство актуальности ранее запущенного процесса приложения на 8000. Для проверки ветки недоступной генерации LLM намеренно отключена настройками тестового экземпляра; внешний ML не подменён.

## Исправление интерфейса

При ошибке LLM сервер возвращал полученный ML-результат и `warning=true`, но обработчик ошибки в браузере показывал только ML-сообщение и ошибку, пропуская предупреждение о помехах/низкой уверенности. Теперь единый вывод предупреждения вызывается и для успешного ответа, и для ошибки. Проверки JS воспроизводят ответ 503 с warning=true/false, проверяют сохранение ML-сообщения, количество предупреждений, отсутствие предпросмотра и запроса отправки. Используется минимальный DOM-двойник, без утверждения о проверке реального браузера.

## Проверки и воспроизведение

Полный запуск с разрешённой интеграционной проверкой: **97 Python-тестов**, включая 20 штатных тестов организатора и один интеграционный тест с циклом по всем 195 парам; **2 Node-теста**. Ошибок нет. Предупреждения Starlette/httpx и PyMuPDF остаются прежними. Проверка синтаксиса app.js и git diff --check проходят.

Из корня репозитория, при уже работающих сервисах и локально подготовленном корпусе:

```powershell
$env:MECHANIC_LIVE_CHECKS='1'
try {
    & 'E:\хакатон\.venv\Scripts\python.exe' -m pytest tests neurodvs_hackathon_mock_2026-11-16/tests -q -p no:cacheprovider
} finally {
    Remove-Item Env:MECHANIC_LIVE_CHECKS
}
node --test tests/frontend.test.cjs
node --check mechanic/static/app.js
openspec validate hackathon-mvp --strict
git diff --check
```

По умолчанию интеграционная проверка пропускается: она требует явно включённого MECHANIC_LIVE_CHECKS=1 и **не запускает сервисы сама**. Она делает только 195 запросов POST /diagnose и проверяет запрет отправки через приложение для каждой пары; POST /tickets отсутствует. Существующие заявки пользователя не изменяются. Отдельные тесты ТОиР используют контролируемый транспорт или экземпляр заглушки внутри тестового процесса.

Локальные подробности: `corpus/stage-8-live.json` (результаты 195 пар) и `corpus/stage-8-search.json` (показатели поиска и совпадение хешей). Эти файлы остаются игнорируемыми; тексты PDF, OCR и ключи не публикуются.
