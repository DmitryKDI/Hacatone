# Проверка 6.1 и 8.4

26 ноября 2026 года. Интерфейс 6.1 реализован и проверен в Microsoft Edge, включая эмуляцию ширины 375 и 320 CSS px. Полная приёмка обеих задач остаётся открытой: реальная LLM не настроена, физический смартфон и чтение вердикта пользователем за десять секунд не проверены.

## Изменения

- Краткий вердикт содержит выбранную машину/проверку и пять полей: статус, тип, уверенность ML, риск, следующее действие. Уверенность не выдаётся за риск; неизвестный риск обозначается явно. Непригодная запись имеет приоритет над остальными признаками.
- Подробности раскрываются отдельно в порядке «наблюдения → гипотезы → проверки → возможный ремонт → источники → ограничения». Утверждения сохраняют точные выдержки и ссылки с физическими страницами. Риски и ограничения требуют такого же подтверждения, как остальные технические утверждения; верификатор получает раздел утверждения.
- На узком экране убрана вложенная прокрутка диалога, после диагностики экран переходит к вердикту. Поля и кнопки переносятся, элементы ввода имеют шрифт 16 px, кнопки — высоту не менее 44 px.
- Исправлен обнаруженный риск работы с прежней серверной парой: до успешного подтверждения нового выбора действия заблокированы. При смене пары прежние сообщения и предпросмотр очищаются.

Успешный ответ LLM, длинные реальные рекомендации, реальные конфликтующие цитаты и подтверждение заявки через браузер в этой проверке отсутствуют. DevTools после проверки закрыты.

## Ручная сверка источников

Повторно визуально сверены четыре сохранённых изображения страниц оригиналов с локальным реестром numeric_passages: 236-re / 19, 536-re / 158, 5234-rk / 9, 409-rk / 77. Проверены числа, единицы, границы диапазонов и условия прогрева/частоты вращения/длительной эксплуатации либо тип свечей. Для 536-re физическая страница 158 соответствует печатной 157; номер ссылки остаётся физическим. Ошибок в этих четырёх выдержках не обнаружено. Оригиналы, изображения и извлечённые тексты остаются в игнорируемом локальном корпусе.

Эта сверка подтверждает выбранные основания, но не заменяет проверку ответов настоящей модели. Контрактные тесты проверяют сохранение буквальных цитат и адресов ссылок; новые положительные ответы модели для ручной оценки не генерировались.
