Источник проверки уровня масла — 236 РЭ, физическая страница 34. Пара O710HH78 / S-0014 показала конфликт источников и подходит для проверки блокировки заявки.
- Для репетиции вопрос по этому отклонению: «Как контролировать уровень масла после остановки двигателя?». Проверенная команда для черновика: «Подготовь заявку на контроль уровня масла по меткам указателя после остановки двигателя на ровной площадке. Включи условие о времени ожидания из руководства. Только контроль уровня».
- Вопрос по руководству: «Какое давление масла допустимо на прогретом двигателе при номинальной частоте и на холостом ходу?» для выбранного ЯМЗ-236М2. В контрольном наборе ожидаемое основание — 236 РЭ, физическая PDF-страница 19; показывать фактически найденное и проверенное основание. Числовые значения в сценарий не копируются.
- Сбой: **P456AT178 / S-0003**, check_failed. Ожидается предложение повторить запись без диагноза и заявки.

Не приписывать измеренное снижение простоев, промышленную готовность, качество реального автопарка или точность собственной ML-модели.
