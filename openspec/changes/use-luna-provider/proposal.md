# ТЗ на перевод «Цифрового механика» на GPT‑6 Luna

## Why

Для демонстрации нужна версия, которая использует GPT‑6 Luna для принятия решений, ответа и проверки источников. Ранее эта модель прошла полный сценарий с Mock ТОиР, а последний сохранённый сценарий GigaChat остановился на подготовке заявки.

## What Changes

- Ветка `luna` создаётся от актуальной `gigachat` и использует модель `gpt-6-luna` через серверный OpenAI Chat Completions API.
- **BREAKING** Из настроек ветки удаляется выбор LLM-провайдера и модели. Старые настройки можно убрать из локальной конфигурации. Единственная учётная настройка Luna — `OPENAI_API_KEY`.
- Для диагностики, поиска по PDF, проверки выдержек и подтверждения заявки сохраняются существующие серверные правила. В модель передаются текст и метаданные, необходимые для текущей задачи.
- Ключ используется в заголовке авторизации к OpenAI. Браузер и журналы получают только безопасную информацию о состоянии интеграции.

## Capabilities

### New Capabilities

- `llm-providers` — фиксированная интеграция GPT‑6 Luna и требования к защите данных ветки. Она уточняет незавершённую многопровайдерную спецификацию `hackathon-mvp` для ветки `luna`.

### Modified Capabilities

В `openspec/specs/` ещё нет опубликованной спецификации провайдеров.

## Impact

Серверные настройки, HTTP-адаптер модели, индикатор модели в чате, тесты, инструкция запуска и диагностический скрипт. Контракты Mock ML и Mock ТОиР и формат поискового индекса сохраняются.
