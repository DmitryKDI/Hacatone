# Text generation with GPT‑6 Luna

## Purpose

Цифровой механик использует GPT‑6 Luna для работы с текстовыми выдержками, инструментами агента и проверкой источников.

## ADDED Requirements

### Requirement: Единственная модель агента

Сервер SHALL использовать `gpt-6-luna` для выбора инструментов, формирования ответа и проверки оснований. Настройки предыдущих провайдеров SHALL NOT менять модель или адрес API.

#### Scenario: Миграция локальной конфигурации

- **WHEN** в процессе или локальном файле остались настройки GigaChat, Yandex или прежнее значение `OPENAI_MODEL`
- **THEN** при наличии `OPENAI_API_KEY` сервер выполняет запрос только к OpenAI Chat Completions с моделью `gpt-6-luna`

#### Scenario: Ключ недоступен

- **WHEN** пользователь запрашивает ответ модели без настроенного ключа
- **THEN** приложение объясняет, как настроить интеграцию, без запроса к API и без создания заявки
- **AND** нормальная и непригодная ML-проверки продолжают работать без ключа

### Requirement: Защита ключа и минимизация передаваемых данных

Сервер SHALL брать ключ из окружения или локального игнорируемого файла, передавать его только в заголовке авторизации на фиксированный HTTPS-адрес OpenAI и исключать из браузерных ответов, журналов, примеров конфигурации и поставки. Сервер SHALL исключать идентификаторы машины и проверки из структурированного результата диагностики, передаваемого модели, и задавать `store=false`.

#### Scenario: Ошибка внешнего API

- **WHEN** ответ API с ошибкой содержит ключ или другой текст запроса
- **THEN** UI и журнал содержат безопасное описание ошибки и служебные поля, без тела ответа API

#### Scenario: Ключ попал в данные сообщения

- **WHEN** ключ из конфигурации присутствует в сформированном запросе или в декодированном ответе модели
- **THEN** сервер отклоняет данные и возвращает безопасное сообщение

### Requirement: Проверяемый текстовый ответ

Сервер SHALL выполнять поиск по локальным фрагментам и проверять ответ Luna по выдержкам и области применения, сохраняя подтверждение человека перед отправкой заявки.

#### Scenario: Диагностика до номера заявки

- **WHEN** ML вернул пригодное отклонение, Luna сформировала обоснованный ответ и механик подтвердил предпросмотр
- **THEN** сервер проверяет выдержки и отправляет один запрос в Mock ТОиР, а интерфейс показывает фактически возвращённый номер
- **AND** до подтверждения отправка отсутствует
