# Прямой ответ и источники

## ADDED Requirements

### Requirement: Прямой ответ на вопрос механика

Если вывод подтверждён, чат SHALL начинать ответ с результата и практически значимого условия. На однозначный закрытый вопрос ответ SHALL начинаться с «Да» или «Нет». При неопределённости чат SHALL объяснять, какого факта, результата осмотра или источника недостаёт.

#### Scenario: Осмотр при подозрении на ранний впрыск

- **WHEN** механик спрашивает про отметку для `M333YK47 / S-0005`
- **THEN** ответ сообщает, что отметки «метки не совпадают» достаточно для подготовки проверенной заявки на регулировку по п. 5.12.1 РК, а измеренный угол вводить не нужно. «Метки совпали» сохраняет результат без заявки на регулировку; отклонение по топливоподаче остаётся.

#### Scenario: Раскрытие доказательств

- **WHEN** механик открывает подробности проверенного ответа
- **THEN** отдельно видны наблюдения, гипотезы и подтверждённые действия, а для технической рекомендации есть применимая выдержка, документ и физическая страница PDF. Нормативы сохраняют исходные единицы и условия.

### Requirement: Следующее действие при отсутствии основания

Когда подтверждённого ответа нет, чат SHALL показывать обычную реплику, объяснять предел знания и предлагать общее безопасное действие с явной пометкой. Отправка заявки MUST оставаться заблокированной.

#### Scenario: Вопрос вне корпуса

- **WHEN** основание для запрошенной работы отсутствует
- **THEN** ответ предлагает дефектовку узла по порядку автопарка и явно сообщает, что заявка не отправлена. Если есть близкий проверенный раздел, указывается его связь с вопросом. Неподтверждённые нормативы и порядок работ отсутствуют.

#### Scenario: Временный сбой

- **WHEN** проверка источника, поиск или вызов модели недоступен
- **THEN** ответ называет недоступный этап и предлагает конкретное действие, например повторить запрос после восстановления. Ответ не утверждает, что инструкции в руководстве нет.

### Requirement: Краткое объяснение конфликта источников

Чат SHALL показывать факт расхождения, оба подтверждённых источника и безопасное действие. Согласованное заказчиком правило для демонстрации SHALL быть явно помечено как решение для этого случая. Зависимая заявка MUST оставаться заблокированной до уточнения.

#### Scenario: Тепловые зазоры ЯМЗ‑236

- **WHEN** для рассматриваемой модификации показано расхождение РЭ и РК о температуре двигателя
- **THEN** ответ показывает обе проверенные формулировки с их страницами, выделяет согласованное для демонстрации условие «на холодном двигателе» и объясняет, что ожидание 15 минут само по себе не подтверждает нужную температуру.

#### Scenario: Другой спорный норматив

- **WHEN** в инструкциях различаются значения либо порядок действий для одинаковых условий
- **THEN** ответ не усредняет и не выбирает более строгое значение самостоятельно; механик получает конкретный вопрос для уточнения применимости к модификации.
